# Hadoop lab

Use the complete [lesson](https://kadamq.github.io/bigdata/hadoop/) for installation, configuration and execution. All scripts are intended for the local WSL2 Ubuntu teaching environment only. Complete the starter Java file or use the solution. Never format an existing HDFS installation.

## Optional Python lab

After the Java exercise, use [Hadoop Streaming with Python](streaming/README.md) to run the same WordCount transformation and a grouped-average exercise. The directory includes scripts, sample CSV data, expected outputs and commands for local checking and the existing Hadoop 3.5.0 environment. Python 3 must be available wherever the tasks execute.
